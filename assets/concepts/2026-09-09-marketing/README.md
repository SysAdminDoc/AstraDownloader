# Astra Downloader v2.15.1 marketing review

This folder keeps the starting point, discarded captures and selected assets together. It is a review record, not a second application or a set of alternative project identities.

## Selected direction

Keep the original folded-A icon. Its green and orange shape remains recognizable on dark and light surfaces, including small sizes. The [identity board](brand-review.html) shows the unchanged artwork from 16 to 128 pixels. No replacement logo is being applied.

The README uses four captures from the portable executable. Both release layouts were opened offscreen on private desktops and produced the same seven review states. The example queue was seeded deliberately; it isn't a throughput benchmark or evidence of a private-site download. The first-run profile is disposable, and helper probes were not started for these screenshots.

The [share-card source](../../marketing/social-card.html) uses the existing icon and the actual Download-page capture. Dark is the selected card; light is retained as an alternative. The files are ready for reuse, but no GitHub Settings social-preview upload is claimed.

## Review decision

The new README explains the two downloads before advanced configuration, shows the actual app, and puts detailed controls in a separate guide. Its cookie and network descriptions now match the implementation's limits. The retained icon is more suitable than an unneeded redesign.

This is an improvement over the original text-only README. Source checks and packaged checks are recorded separately. Browser pairing, a signed Windows installation and account-gated downloads have not been validated by this pass. The application remains unsigned.
